## ⚡ Quick Start & Local Setup

### 1. Clone the Repository
```bash
git clone https://github.com/pasha804/pasha-ai-desktop-assistant.git
cd pasha-ai-desktop-assistant
```

### 2. Launch Locally
Launch directly in any modern browser:
```bash
# Windows
start index.html

# macOS
open index.html

# Linux
xdg-open index.html
```

Or spin up an instant local web server:
```bash
npx serve .
# or
python -m http.server 8080
```
